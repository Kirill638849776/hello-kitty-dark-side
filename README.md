## 📖 О проекте

**Hello Kitty - The Dark Side** — это интерактивное приложение с элементами психологического хоррора. Программа воспроизводит видео, показывает диалоговые окна с выбором и заканчивается открытием блокнота с загадочным сообщением.

### 🎯 Особенности

- 🎬 **Воспроизведение видео** с звуком в отдельном окне
- 💬 **Интерактивные диалоги** с кнопками
- 🎨 **Стилизованный интерфейс** в темных тонах
- 📝 **Финальное сообщение** в блокноте
- 📦 **Один EXE файл** с встроенным видео
